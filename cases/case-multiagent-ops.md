# ケース: 多エージェント運用チームの構築

> あるオンライン事業の運用を、6名の役割特化型AIエージェントによる「チーム」として自動化した事例。

## 課題

小規模・個人運営の事業では、戦略立案・コンテンツ企画・集客・商品設計といった業務が
すべて1人に集中し、日々の運用が後回しになりがちでした。
人を雇うほどの規模ではないが、放置すると事業が止まる——この間を埋める必要がありました。

## 設計したもの

役割を6つに分け、それぞれに専門特化したAIエージェント（仮想社員）を定義しました。

| 役割 | 担当領域 |
|------|---------|
| マネージャー | 全体統括・進捗確認・オーナーとの対話窓口 |
| SEO最適化担当 | タイトル・検索流入の最適化 |
| コンテンツ企画担当 | 企画・台本づくり |
| コミュニティ担当 | 共感を生むコピー・コミュニケーション設計 |
| 商品設計担当 | 商品・導線（ファネル）の設計 |
| 広報戦略担当 | 集客チャネル全体の戦略 |

各エージェントは**ペルソナ定義ファイル**を持ち、口調・判断基準・優先順位までキャラクター化。
オーナーは「マネージャー」と対話するだけで、必要に応じて各専門家の知見が引き出される構造です。

## 仕組みのポイント

- **毎朝の無人稼働**: スケジューラ連携で毎朝定時にチーム全員が自動起動し、その日のレポートを生成
- **証跡ベースの完了判定**: 「指示を書いた」では完了とせず、レポート出力・記録の更新など*オーナーから見える証跡が残ること*を完了条件に設計。自動化が「動いたつもり」で止まる事故を防止
- **対話で指示**: マネージャーにチャットで話しかけるだけで、現状確認→報告→次の指示出しまでが回る

## 成果

- オーナーが手を動かさなくても、日次で運用提案が上がってくる体制が成立
- 専門役割ごとに出力が分かれるため、「次に何をすべきか」が毎朝はっきりする
- 人を雇わずに「チームで運営している」状態を再現
