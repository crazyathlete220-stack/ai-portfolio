# AI事業開発者 ポートフォリオ

> 公開ページ: [日本語](index.html) ｜ [English](index-en.html)


AIエージェントを使って「事業の運用そのもの」を自動化・仕組み化することを専門にしています。
単発のツール作成ではなく、**人手をかけずに事業が回り続ける体制**を設計・実装するのが得意領域です。

- 役割特化型のAIエージェントによる業務分担
- スケジューラ連携による無人の日次運用
- API連携による定型作業の完全自動化
- 「証跡が残ること」を完了条件にした、止まらない自動化設計

## 使っている技術・ツール

- **AIオーケストレーション**: Claude Code / 役割別ペルソナ定義 / マルチエージェント協調
- **自動化基盤**: スケジューラ連携（cron的な定時起動）、heartbeat・証跡ベースの完了判定
- **実装**: Node.js / TypeScript / 各種Web API連携（OAuth含む）/ React・Vite
